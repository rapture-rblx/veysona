# Veysona Stereo Diagnostics Update (v1.28 compatibility patch)

Adds stereo correlation and left/right RMS balance to existing offline clip analysis, including a phase cancellation warning. Also exposes the measurements in the CLI analysis command. Regression coverage tests in-phase, inverted, gain-skewed and silent stereo material.

This is a source-compatible patch to v1.28; it is not a new certified Windows release or a 9/10 audio-quality claim.
